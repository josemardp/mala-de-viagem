# Mala de Viagem (mudou de endereço)

Desde 20/11/2026 a calculadora de mala mora no repositório **calculadoras**:

- Site: https://josemardp.github.io/calculadoras/mala/
- Código: https://github.com/josemardp/calculadoras

Este repositório ficou só com um `index.html` que redireciona o link antigo
(https://josemardp.github.io/mala-de-viagem/) para o novo, e foi arquivado.
Os remédios cadastrados no navegador continuam valendo, porque o endereço base
é o mesmo (`josemardp.github.io`) e as chaves de armazenamento não mudaram.

O código antigo está no histórico do Git (commit `977d831` e anteriores).
